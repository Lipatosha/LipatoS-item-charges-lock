# LipatoS - Запрет изменения зарядов

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который запрещает обычным игрокам вручную изменять количество зарядов предметов.

Вместо всплывающего сообщения модуль показывает подсказку при наведении: **«Количество изменяет только ГМ»**. Автоматический расход и восстановление зарядов механиками игры не блокируются.

## Версия

**1.0.1**

## Совместимость

- Foundry VTT: **14**
- D&D 5e

## Возможности

- запрещает игрокам вручную изменять текущее количество зарядов предмета;
- запрещает изменение максимального количества зарядов;
- блокирует изменение через поля, клики, клавиатуру и элементы списка предметов;
- при наведении показывает подсказку **«Количество изменяет только ГМ»**;
- не блокирует автоматический расход и восстановление зарядов механиками D&D 5e;
- ГМ и Assistant GM работают без ограничений.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-item-charges-lock/main/module.json`
